# Гипотеза Римана на одной странице

**Редакция 9.0 · Схема доказательства** · [Препринт на Hexagon 2611.01031v1](https://hexagonmath.org/abs/2611.01031v1) ([PDF](https://hexagonmath.org/pdf/2611.01031v1)) · [DOI препринта 10.5281/zenodo.24459320](https://doi.org/10.5281/zenodo.24459320)

**Теорема (гипотеза Римана и $L$-функции Дирихле).** *Для всякого целого $N \ge 1$ и характера Дирихле $\chi \bmod N$ выполнено $L(s, \chi) \ne 0$ в полуплоскости $\Re s > 1/2$ (при $\chi \ne 1$ или $s \ne 1$), а все нули $L(s, \chi)$ в полосе $0 < \Re s < 1$ лежат на прямой $\Re s = 1/2$. В частности, все нетривиальные нули $\zeta(s)$ имеют $\Re s = 1/2$.* *[Lean: `Main.lean:4–12`, `Statements.lean:3–16`]*

**1. Нуль нарушил бы оценку на окне.** Зафиксируем конечное семейство $\mathcal F = \{(a_i, \chi_i)\}$ с весами $a_i > 0$. Исключим главные характеры модулей $N_i > 1$. Сглаженную сумму $R_\chi(y) = \sum_{n \le y} \Lambda(n)\chi(n)(y/n - 1)$ центрируем по формуле $G_1(y) = R_1(y) - y\log y + (1+\gamma)y$ или $G_\chi(y) = R_\chi(y) + y(L'/L)(1,\chi)$ и положим $G_{\mathcal F}(y) = \sum_i a_i \Re G_{\chi_i}(y)$. Преобразование Меллина $\Phi(s) = \int_1^\infty G_{\mathcal F}(y)y^{-s-1}\,dy$ регулярно в $s = 1$. В нуле $\rho$ функции $L(s,\chi_i)$ вычет равен $-\sum_i a_i\{m_i(\rho)+m_i(\bar\rho)\}/[2\rho(\rho-1)]$. При $a_i > 0$ слагаемые числителя не сокращаются. Для вещественного нуля $\rho \in (0,1)$ вычет положителен. После замены $u = \log y$ гамма-плотность $\frac{\sigma^{k+1}}{k!}u^k e^{-\sigma u}\,du$ сосредоточивает интеграл для $D_k(z) = (-1)^k\Phi^{(k)}(z)/k!$ на $[U, (1+\delta)U]$ вблизи $k/\sigma$. Пусть $G_{\mathcal F}(y) \le C y^\theta$ выполнено на сколь угодно далёких окнах $[Z, Z^{3/2}]$ ($\delta = 1/2$). Полюс от любого $\chi_i \in \mathcal F$ при $\Re s > \theta$ противоречит оценке производных. В вещественном случае берут $\Re D_k(\sigma)$. При сдвиге выделяют ближайший полюс на расстоянии $< \sigma - \theta$ от $\sigma + iv$ и сравнивают $|D_k(\sigma + iv)|$ с вещественной производной. Предел $\theta \downarrow 1/2$ берут при фиксированном семействе, содержащем $\psi$. Функциональное уравнение для примитивного характера $s \leftrightarrow 1 - s$ и конечные эйлеровы множители исключают $0 < \Re s < 1/2$. *[Lean: `CharFamily.lean:10–45`, `landauWindow.lean:20–45, 83–154`, `ZeroFreeOfRpowWindow.lean:11`, `ClaimStrip.lean:7–75`]*

**2. Отбор характеров.** На всём окне $[Z, Z^{3/2}]$ работает одна пара $(q, d)$ ($q \equiv 3 \bmod 8$, $d \equiv 7 \bmod 16$, $p \mid d+1$ для нечётных простых $p \le u$). Вещественное круговое $2$-расширение и поле характера вместе имеют степень $n=c\,2^e$, где $1\le c\le\operatorname{ord}(\psi)$ и $n \asymp x^{2+8\varepsilon}$. У CM-поля $E$ степень $[E:\mathbb Q] = 4n$ и группа $G = E_0 \times H$, где $E_0 = (\mathbb Z/2\mathbb Z)^2$ и $|H| = n$. Сопряжение $\mathrm{cconj} = ((1,1),0)$ и сдвиг $t \in H$ переводят $G \setminus \Phi$ (при $\Phi = \{g_1 = 0\}$) на $\Phi$ по правилу $\mathrm{partner}(t,g) = \mathrm{cconj} + g + ((0,0), t)$ с обратным $\mathrm{partner}(-t, \cdot)$. Ортогональность даёт $\mathrm{ASK} - \mathrm{MAIN} = \mathrm{De}$. В сумме $\mathrm{ASK}$ срезки $(A/\ell^e - w)_+ \log\ell$ входят дважды для нечётных степеней инертных простых в $\mathbb Q(\sqrt{-d})$ вне $\{2,q,d\}$. В отдельной сумме для $d$ каждое слагаемое имеет множитель $\log d$. Двойственная сумма $\mathrm{De}$ содержит $w \cdot \mathrm{GPsi}(\xi, A/w)$. Усреднение по $A_0 \le H$ оставляет из $\widehat G$ аннулятор $\Psi_A$. Оценка дополнения $\Psi_A \setminus K_p$ сводит $G_{\mathcal F}(x) \le x^{1/2 + (e_D+e_L+7)\varepsilon}$ на $[Z, Z^{3/2}]$ к оценке $\mathrm{gap}_A(u_0) = \sum (\mathrm{ASK} - \Re\,\mathrm{MAIN})$. *[Lean: `ExistsPageN.lean:27–49`, `ChBalance.lean:200`, `ChCore.lean:56–75, 283–343`, `SigALe.lean:38`]*

**3. Высота $2$ и нечётные степени.** Для $\mathrm{ASK}$ используем $m \asymp x^{1/2-\varepsilon/16}$ ступеней с сигнатурами $(k+j-1, m-j)$ ($1 \le j \le m$, $k \asymp x^{9/2+10\varepsilon}$) и $m-1$ переходов. Последняя сигнатура равна $(r, 0)$, где $r = k+m-1$. В простом $\ell \ge 5$ хорошей инертной редукции над $\mathbb Q(\sqrt{-d})$ формальная группа имеет высоту $2$. Для сравнения служит ряд Любина–Тейта $\mathrm{ltLog}(X) = \sum_{j \ge 0} X^{\ell^{2j}}/\ell^j$. В обратном ряду $\exp_{\mathrm{LT}}(Z) = \sum_{r \ge 1} c_r Z^r = Z - Z^{\ell^2}/\ell + \cdots$ возможны степени, сравнимые с единицей по модулю $\ell^2 - 1$. В степени $r$ показатель $\ell$ в знаменателе не превосходит $(r-1)/(\ell^2-1)$. Формула Лежандра для $r!$ даёт $(r - s_\ell(r))/(\ell - 1)$. Для $r!$-струй получаем
$$
v_\ell(r!\, c_r) \ge \left(\frac{1}{\ell - 1} - \frac{1}{\ell^2 - 1}\right)r - (\lfloor\log_\ell r\rfloor + 1) = \gamma_\ell\, r - (\lfloor\log_\ell r\rfloor + 1),\qquad \gamma_\ell = \frac{\ell}{\ell^2 - 1} = \sum_{\substack{e \ge 1 \\ e\ \text{нечётно}}} \ell^{-e}.
$$
При обыкновенной расщеплённой редукции высота равна $1$, и разность равна $\frac{1}{\ell-1} - \frac{1}{\ell-1} = 0$. Усечение по формуле $\alpha - \min(\alpha, c) = \max(\alpha - c, 0)$ даёт срезки суммы $\mathrm{ASK}$. *[Lean: `CMGoodModels/Statement.lean:35–49`, `GaussJetBounds/Statement.lean:98–107`, `FormalGroupSystem.lean:548`, `AdmissibleAtGeneratorPlaces.lean:214`]*

**4. Наклоны при фиксированном $u_0$.** Для решёток $M_u$, $N_u$ и $P_{u_0}$ берём одни и те же положительные веса рангов. Положим $\bar\mu(u_0) = \mathrm{wmean}_d(\mu(N_u) - h(u))$. Четыре неравенства имеют вид
$$
\begin{aligned}
(\mathrm{Loss})\ \mathrm{ASK}(u_0) - \mathrm{Ga}(u_0) \le \mathrm{LoP},\quad
&(\mathrm{Gain})\ \mu(M_u) + \mathrm{Ga}(u_0) + \mathrm{Fo}(u_0) - \mathrm{Ee}(u_0, u) - \mathrm{Lo}_5 \le \mu(N_u),\\
(\mathrm{Slope})\ \bar\mu(u_0) - \log|W_{u_0}| - \mathrm{Err}_{\mathrm{HN}} \le \mu(P_{u_0}),\quad
&(\mathrm{Div})\ \mu(P_{u_0}) + h(u) - \mathrm{Fo}(u_0) \le S_{\rm div} - \sum_t a_t\log T(u_0,u) + \mathrm{Err}_{\rm Div}.
\end{aligned}
$$
Здесь $S_{\rm div}=\sum_t m[\phi(a_t)-a_t\log\Omega]$, где $\phi(a)=a\log a-a$. Усредним $(\mathrm{Gain})$ и $(\mathrm{Div})$ с теми же весами. Тогда $(\mathrm{Slope})$ исключает промежуточный наклон. На ступени $(r, 0)$ сокращаются $\pm\mathrm{Fo}(u_0)$ и $\pm\mu(P_{u_0})$. Подсчёт ограничивает $\log T$ снизу. Его главный член компенсирует ведущую часть $\mathrm{Ee}(u_0,u)$. Формула периодов $\log\Omega_{\mathrm{val}} = \gamma + \log(2\pi/\mathrm{rd}(E)) - \Re(L'/L)(1,\chi_{-d})$ сокращает $\log(\pi/v)$ и даёт $\mathrm{Data.Main}(u_0) = \sum_{t,j} \Re\,\mathrm{MAIN}$. Вычитая $\mathrm{Data.Main}(u_0)$, оцениваем $\mathrm{gap}_A(u_0)$. *[Lean: `QuotientSlopeBoundsWith.lean:19–34`, `StatementFrameF.lean:26`, `MeanBoundSecondForm.lean:107–155`, `MeanLogPeriodChowlaSelberg.lean:58–84`, `ChTop.lean:11–46`]*

**5. Выбор показателей.** Последовательное накопление по ступеням $1 \le j \le m$ стоит $\sum_{j=1}^m j \asymp m^2$. Для вещественного положительного $m$ барьер $x^{2/3}$ задаётся минимумом $\min_m(x/m + m^2) = 3(x/2)^{2/3}$ при $m = (x/2)^{1/3}$. В доказательстве $m$ блоков $F.\mathrm{L}_{j,t}$ делят общий запас $O(f m b x^\varepsilon)$ при $f=2n$. Цена $m^2$ снижается до $m$. Запишем $m = x^a$, $k = x^\kappa$, $n = x^\nu$. Ограничения имеют вид $4a \le \nu$ ($m^4 \le n$) и $5a + \nu \le \kappa$ ($m^5 f L \ll k$ для вложения в $2^{k-2}$ слов). Минимум $\max(1-a,\ 1+a-\kappa,\ a,\ \kappa-2\nu)$ равен $\theta_*(\nu) = \max\bigl(\tfrac{1}{2},\ 1 - \tfrac{\nu}{4},\ \tfrac{2-2\nu}{3},\ \tfrac{5-\nu}{6}\bigr)$. При $\nu_* = 2$ значение $\theta_* = 1/2$ достигается только в $(a, \kappa) = (1/2, 9/2)$. Получаем $G_{\mathcal F}(x) \le x^{1/2 + O(\varepsilon)}$ и заключение оконного критерия. *[Lean: `DefFam`, `Formalism.L2.DIV.DefFam.L`, `RowLat.lean:202–216`, `LiftLat.lean:147–153`, `DataArith.lean:200`, `MPowFiveMulFMulLLe.lean:9–40`, `CoreGm.lean:12–74`, `TopPlug.lean:12–18`]*
